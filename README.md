## Resumo:
Awakened é um jogo desenvolvido para Windows do gênero RPG de Turno. Awakened tem como temática transversal os direitos humanos, contando uma história ambientada na ditadura militar do Brasil com o intuito de representar aspectos importantes do período por meio de uma mídia interativa. Pelos olhos de personagens fictícios que sofrem uma tragédia pessoal, a narrativa se baseia em fatos reais da época para demonstrar como a vida era para muitas pessoas no Brasil comandado pela ditadura.

## Mecânicas Principais:  
* Combate em turnos entre os protagonistas e os inimigos.  
* Action Command, em que o jogador realiza comandos no momento certo para potencializar ataques ou ações defensivas.  
* Exploração em tempo real do mapa, com transição para batalhas quando inimigos detectam o jogador.  
* Sistema de inventário, permitindo coletar, armazenar e utilizar itens durante a exploração e o combate.  
* Sistema de diálogo e escolhas, utilizado para desenvolver a narrativa.  
* Progressão por exploração, obtenção de itens-chave e resolução de desafios para acessar novas áreas.

## Tecnologias Utilizadas:  
* Unity 6 como engine principal para o desenvolvimento do jogo.  
* Linguagem C# para implementação da lógica, mecânicas e sistemas.  
* GitHub para controle de versão e desenvolvimento colaborativo.  
* Photoshop, Krita e Aseprite para criação e edição das artes em pixel art.  
* FL Studio para produção da trilha sonora.  
* Audacity para edição dos efeitos sonoros.  
* Trello para organização das tarefas do projeto. 

## Explicação dos Requisitos Implementados:  
### Sistema de Dados
* Estrutura para gerenciamento das informações do jogo, como personagens, inimigos, itens, diálogos e mapas.
* Organização dos dados para controlar o progresso da história e a evolução do jogador.

### Sistema de Embaralhamento
* Cada região do jogo possui uma lista de inimigos específicos.
* Ao entrar em combate, o sistema seleciona aleatoriamente entre 1 e 3 inimigos dessa lista para formar o grupo de adversários.

### Interface Gráfica
* Interface composta por menus, HUD de exploração e tela de combate.
* Exibição das informações dos personagens, como vida, ações disponíveis, inventário e diálogos.
* Navegação entre menus de forma intuitiva durante a exploração e as batalhas.

### Sistema de Áudio
* Trilha sonora para ambientação das diferentes áreas do jogo.
* Efeitos sonoros durante exploração, combate, interação com NPCs e utilização de habilidades.
* Áudio utilizado para reforçar a imersão e fornecer feedback ao jogador.

### Persistência de Dados
* Sistema de salvamento do progresso do jogador.
* Armazenamento das informações de exploração, inventário e progresso da história para continuidade da partida.

## Abstract:
Awakened is a Turn-Based RPG game developed for Windows. Awakened explores human rights as its central theme, telling a story set during the Brazilian Dictatorship that spanned from 1964 until 1985, with the intent of representing important aspects of this period through an interactive medium. Through the perspective of fictional characters that go through a personal tragedy, the narrative is based on real events of that time to demonstrate how life was for many people in Brazil under the dictatorship’s command.

## Main Gameplay Mechanics
* Turn-based combat between the protagonists and enemies.
* Action Command system, where players perform timed inputs to enhance attacks or defensive actions.
* Real-time map exploration, transitioning into battles when enemies detect the player.
* Inventory system, allowing players to collect, store, and use items during exploration and combat.
* Dialogue and choice system used to develop the narrative.
* Progression through exploration, obtaining key items, and solving challenges to unlock new areas.

## Technologies Used
* Unity 6 as the primary game engine.
* C# programming language for implementing game logic, mechanics, and systems.
* GitHub for version control and collaborative development.
* Photoshop, Krita, and Aseprite for creating and editing pixel art assets.
* FL Studio for composing the game's soundtrack.
* Audacity for editing sound effects.
* Trello for project management and task organization.

## Implemented Features

### Data System
* Data structures used to manage game information, including characters, enemies, items, dialogues, and maps.
* Organized data management to control story progression and player progression.

### Enemy Randomization System
* Each region contains a predefined list of enemies.
* When a battle begins, the game randomly selects between one and three enemies from that region's list to create the encounter.

### Graphical User Interface
* User interface composed of menus, an exploration HUD, and battle screens.
* Displays character information such as health, available actions, inventory, and dialogues.
* Intuitive navigation between menus during exploration and combat.

### Audio System
* Background music designed to match the atmosphere of each area.
* Sound effects for exploration, combat, NPC interactions, and skill usage.
* Audio feedback enhances immersion and reinforces player actions.

### Save System
* Allows the player's progress to be saved.
* Stores exploration data, inventory, and story progression so the game can be resumed later.
