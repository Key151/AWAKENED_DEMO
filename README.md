# AWAKENED DEMO

## Abstract:
Awakened is a Turn-Based RPG game developed for Windows. Awakened explores human rights as its central theme, telling a story set during the Brazilian Dictatorship that spanned from 1964 until 1985, with the intent of representing important aspects of this period through an interactive medium. Through the perspective of fictional characters that go through a personal tragedy, the narrative is based on real events of that time to demonstrate how life was for many people in Brazil under the dictatorship’s command.

## Main Gameplay Mechanics
* Turn-based combat between the protagonists and enemies.
* Action Command system, where players perform timed inputs to enhance attacks or defensive actions.
* Real-time map exploration, transitioning into battles when enemies detect the player.
* Inventory system, allowing players to collect, store, and use items during exploration and combat.
* Dialogue and choice system used to develop the narrative.
* Progression through exploration, obtaining key items, and solving challenges to unlock new areas.

## Technologies Used
* Unity 6 as the primary game engine.
* C# programming language for implementing game logic, mechanics, and systems.
* GitHub for version control and collaborative development.
* Photoshop, Krita, and Aseprite for creating and editing pixel art assets.
* FL Studio for composing the game's soundtrack.
* Audacity for editing sound effects.
* Trello for project management and task organization.

## Implemented Features

### Data System
* Data structures used to manage game information, including characters, enemies, items, dialogues, and maps.
* Organized data management to control story progression and player progression.

### Enemy Randomization System
* Each region contains a predefined list of enemies.
* When a battle begins, the game randomly selects between one and three enemies from that region's list to create the encounter.

### Graphical User Interface
* User interface composed of menus, an exploration HUD, and battle screens.
* Displays character information such as health, available actions, inventory, and dialogues.
* Intuitive navigation between menus during exploration and combat.

### Audio System
* Background music designed to match the atmosphere of each area.
* Sound effects for exploration, combat, NPC interactions, and skill usage.
* Audio feedback enhances immersion and reinforces player actions.

### Save System
* Allows the player's progress to be saved.
* Stores exploration data, inventory, and story progression so the game can be resumed later.
